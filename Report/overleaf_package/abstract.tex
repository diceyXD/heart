\chapter*{\centering ABSTRACT}
\addcontentsline{toc}{chapter}{Abstract}

\noindent Coronary artery disease is a leading cause of mortality worldwide, yet diagnostic decision-making often involves severe uncertainty, incomplete patient observations, and non-invasive test variation across healthcare facilities. Standard discriminative classification models fail under missing evidence and produce uncalibrated confidence estimates. This project develops an end-to-end, deployable probabilistic inference application for coronary heart disease diagnosis using a Discrete Bayesian Network and an MLOps engineering framework. The application utilizes the comprehensive UCI Heart Disease Multi-Center dataset comprising 920 clinical records across four clinical centers (Cleveland, Hungary, Switzerland, and VA Long Beach). A repeatable, data-leakage-free preprocessing pipeline audits missing diagnostic procedures, handles physiological zeros in resting blood pressure and cholesterol, imputes missing values strictly from training statistics, and transforms continuous vitals into clinically validated ordinal states. A Diagnostic Bayesian Network DAG is formulated and parameterized using Discrete Maximum Likelihood Estimation, capturing causal relationships between underlying pathological state and 13 clinical findings while assuming conditional independence given disease presence. Exact probabilistic inference is executed via Variable Elimination, allowing the model to estimate well-calibrated posterior probabilities $P(\text{Heart Disease} \mid \text{Evidence})$ under both complete and partial evidence profiles without imputation at test time. On a held-out stratified test set of 184 cases, the Bayesian Network achieves a classification accuracy of 82.07\%, sensitivity of 85.29\%, specificity of 78.05\%, F1-score of 84.06\%, ROC-AUC of 0.8914, and a Brier calibration score of 0.1433. The application is served through a high-performance FastAPI backend and an interactive Streamlit clinician dashboard with live risk stratification, CPT transparency, and a regulatory medical-use disclaimer. The lifecycle includes experiment tracking in MLflow, artifact versioning, multi-container deployment via Docker and Docker Compose, operational request logging, and a systematic data-drift monitoring plan.
