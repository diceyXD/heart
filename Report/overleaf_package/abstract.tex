\chapter*{\centering ABSTRACT}
\addcontentsline{toc}{chapter}{Abstract}

\noindent Coronary artery disease is a leading cause of mortality worldwide, and early detection is crucial for timely intervention. This project develops an end-to-end probabilistic diagnostic application using the multi-center UCI Heart Disease dataset of 920 patient records. Missing values and institutional recording variations were cleaned, and continuous clinical features were discretized into medical stages using rules derived strictly from the training data. A Discrete Bayesian Network with a Naive Bayes structure was developed and trained using Maximum Likelihood Estimation to model probabilistic dependencies between heart disease and 13 clinical symptoms. Exact probabilistic inference is executed via Variable Elimination, allowing the model to estimate well-calibrated probabilities even when only partial evidence is observed. On a held-out test set of 184 records, the model achieved an accuracy of 82.07\%, sensitivity of 85.29\%, specificity of 78.05\%, F1-score of 84.06\%, and an ROC-AUC of 89.14\%, with a Brier calibration score of 0.1433. The application is served through a FastAPI prediction backend and an interactive Streamlit clinician dashboard with risk stratification and a medical disclaimer, with experiment tracking in MLflow and containerisation using Docker.

\noindent\textbf{Keywords:} Bayesian Networks, Medical diagnosis, Heart disease, pgmpy, FastAPI, Streamlit, Docker, MLOps.
