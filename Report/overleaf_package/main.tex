\chapter{Introduction}

\section{Background and Motivation}

Coronary artery disease (CAD) remains one of the principal causes of morbidity and mortality globally. Timely and accurate identification of individuals at risk of CAD is essential for preventing myocardial infarction, heart failure, and sudden cardiac death. However, clinical decision-making in cardiology is inherently fraught with uncertainty. Physicians routinely encounter heterogeneous diagnostic indicators ranging from subjective patient-reported symptoms (such as chest pain presentation) and non-invasive vitals (resting blood pressure, serum cholesterol, exercise tolerance) to specialized electrocardiographic stress testing and invasive fluoroscopy.

A major challenge in clinical practice is that patients rarely undergo the entire battery of diagnostic investigations during preliminary consultations. Invasive coronary angiography or radioactive thallium scintigraphy may be contraindicated, unavailable, or deferred due to cost and safety considerations. Consequently, real-world clinical datasets exhibit significant missingness across diagnostic modalities. 

Standard discriminative machine learning algorithms---such as Logistic Regression, Support Vector Machines, Random Forests, and Gradient Boosted Trees---are ill-suited for this environment. These traditional models require complete feature vectors at inference time, mandating artificial imputation schemes when evidence is absent. Furthermore, their output scores are frequently uncalibrated margins rather than valid probabilistic measures, providing clinicians with deceptive certainty.

\section{Probabilistic Graphical Models and Bayesian Networks}

Bayesian Networks (BNs) provide a principled, mathematically rigorous framework for reasoning under uncertainty. A Bayesian Network represents joint probability distributions compactly over a set of random variables through a Directed Acyclic Graph (DAG) paired with Conditional Probability Tables (CPTs). In a diagnostic setting, Bayesian Networks offer three fundamental advantages over conventional discriminative classifiers:

\begin{enumerate}
\item \textbf{Native Handling of Partial Evidence:} Through exact probabilistic inference algorithms such as Variable Elimination or Junction Tree propagation, unobserved symptoms or unperformed laboratory tests are marginalized out automatically. The network computes the exact posterior probability $P(\text{Disease} \mid \text{Evidence})$ conditioned strictly on the observed subset without requiring ad-hoc data imputation.
\item \textbf{Calibrated Posterior Probabilities:} Rather than producing uncalibrated decision boundaries, Bayesian Networks generate well-founded statistical probabilities representing the degree of belief in the pathological condition.
\item \textbf{Explainable Causal and Diagnostic Structure:} The graphical topology encodes explicit conditional dependence and independence assumptions, allowing clinicians to inspect both prior distributions and conditional likelihoods across distinct clinical subpopulations.
\end{enumerate}

\section{Integration with MLOps Practices}

While machine learning research often terminates with offline model evaluation, translating a probabilistic model into clinical decision support requires Machine Learning Operations (MLOps). Production deployment demands repeatable data pipelines, continuous provenance tracking, version-controlled artifacts, scalable prediction APIs, interactive clinical user interfaces, containerisation, operational logging, and data drift monitoring.

This project implements an end-to-end, production-ready Bayesian Network diagnostic system using the multi-center UCI Heart Disease dataset. The development workflow incorporates MLflow for experiment tracking, pgmpy for probabilistic graphical modeling, FastAPI for high-throughput RESTful inference, Streamlit for an interactive clinician dashboard, and Docker for cross-platform containerized execution.

\section{Project Objectives}

The primary objectives of this project are:
\begin{itemize}
\item To design a clean, data-leakage-free preprocessing and discretization pipeline for the multi-center UCI Heart Disease dataset.
\item To formulate a clinically grounded Bayesian Network DAG structure and estimate its Conditional Probability Tables using Discrete Maximum Likelihood Estimation.
\item To perform exact probabilistic inference under complete and partial evidence profiles using Variable Elimination.
\item To rigorously evaluate diagnostic sensitivity, specificity, discrimination (ROC-AUC), and probability calibration (Brier score) on a held-out test split.
\item To track all parameters, metrics, CPTs, and dataset provenance cryptographically in MLflow.
\item To expose the inference engine through a validated FastAPI service and an intuitive Streamlit interface featuring live risk stratification, dynamic probability gauges, and a mandatory medical safety disclaimer.
\item To containerise the multi-service architecture using Docker and Docker Compose, and establish comprehensive operational logging and data-drift monitoring protocols.
\end{itemize}

\section{Dataset Description}

The application is developed using the comprehensive UCI Heart Disease dataset, which aggregates records from four international clinical institutions:
\begin{enumerate}
\item \textbf{Cleveland Clinic Foundation}, Cleveland, Ohio, USA ($N = 304$).
\item \textbf{Hungarian Institute of Cardiology}, Budapest, Hungary ($N = 293$).
\item \textbf{University Hospital}, Zurich and Basel, Switzerland ($N = 123$).
\item \textbf{V.A. Medical Center}, Long Beach, California, USA ($N = 200$).
\end{enumerate}

The raw aggregated dataset contains 920 patient instances and 16 attributes. The original target variable is \texttt{num}, representing angiographic disease status ranging from 0 (absence of significant stenosis, defined as $<50\%$ diameter narrowing) to stages 1, 2, 3, and 4 (presence of coronary stenosis in one to four major coronary arteries). In alignment with clinical screening objectives, the target is binarized into \texttt{heart\_disease}, where 0 represents absence and 1 represents the presence of coronary heart disease.

The administrative columns \texttt{id} and \texttt{dataset} are non-clinical indicators and are excluded from predictive modeling, leaving 13 clinical and diagnostic features.

\section{Data Cleaning and Anomaly Correction}

Careful clinical inspection of the raw data revealed domain-specific recording anomalies:
\begin{itemize}
\item \textbf{Resting Blood Pressure (\texttt{trestbps}):} Contains 59 missing values and 1 erroneous entry of $0\text{ mmHg}$, representing unrecorded admission vitals.
\item \textbf{Serum Cholesterol (\texttt{chol}):} Contains 30 explicit missing values and 172 records with $0\text{ mg/dl}$ (predominantly at the VA Long Beach site), reflecting institutional coding conventions where unmeasured lipid panels were recorded as zero.
\end{itemize}

In this pipeline, physiological zeros in \texttt{trestbps} and \texttt{chol} are treated as genuine missing values ($\text{NaN}$) to prevent distortion of probability distributions.

\section{Leakage-Free Preprocessing and Discretization}

Bayesian Networks parameterized with tabular Conditional Probability Tables (Discrete Bayesian Networks) require discrete or categorical state spaces for all nodes. To transform continuous physiological measurements into discrete states without introducing data leakage, a deterministic, domain-knowledge-driven binning strategy is implemented.

To strictly avoid data leakage, all statistical imputers (medians for continuous vitals and modes for categorical observations) are computed \textbf{exclusively on the 736-record training split}. The held-out test split is transformed using these frozen training statistics.

\begin{table}[!htbp]
\centering
\caption{Clinical discretization rules for continuous variables}
\begin{tabular}{lll}
\toprule
\textbf{Feature} & \textbf{Cutoff Bins} & \textbf{Discrete State Labels} \\
\midrule
Age (\texttt{age}) & $[0, 45, 60, 120]$ & \texttt{young}, \texttt{middle}, \texttt{senior} \\
Resting Blood Pressure (\texttt{trestbps}) & $[0, 120, 140, 300]\text{ mmHg}$ & \texttt{normal}, \texttt{elevated}, \texttt{high} \\
Serum Cholesterol (\texttt{chol}) & $[0, 200, 240, 1000]\text{ mg/dl}$ & \texttt{normal}, \texttt{borderline}, \texttt{high} \\
Max Heart Rate (\texttt{thalch}) & $[0, 120, 150, 300]\text{ bpm}$ & \texttt{low}, \texttt{moderate}, \texttt{high} \\
ST Depression (\texttt{oldpeak}) & $[-10.0, 0.0, 1.5, 20.0]\text{ mm}$ & \texttt{none}, \texttt{mild}, \texttt{severe} \\

\end{table}

The remaining categorical variables (\texttt{sex}, \texttt{cp}, \texttt{fbs}, \texttt{restecg}, \texttt{exang}, \texttt{slope}, \texttt{ca}, \texttt{thal}) are cast to standardized string states.

\section{Bayesian Network Topology and Structural Assumptions}

The structure of the Bayesian Network is formulated as a \textbf{Diagnostic Naive Bayes Directed Acyclic Graph (DAG)}. In this topology, the target condition \texttt{heart\_disease} serves as the root parent node directing outward edges to each of the 13 clinical finding nodes:
\begin{equation}
\mathcal{G} = \left( \mathcal{V}, \mathcal{E} \right), \quad \mathcal{E} = \{ (\text{heart\_disease}, X_i) \mid X_i \in \text{Features} \}
\end{equation}

\subsection{Causal Directionality and Structural Rationale}
In clinical pathophysiology, disease states cause symptom manifestations and diagnostic test deviations, not vice versa. Coronary atherosclerosis causes diminished myocardial perfusion, leading to exertional angina (\texttt{exang}), ischemic ST depression (\texttt{oldpeak}), reduced maximum exercise heart rate (\texttt{thalch}), and fluoroscopic vessel calcification (\texttt{ca}). Structuring the target as the parent of the findings reflects this true underlying causal mechanism.

\subsection{Conditional Independence Assumption}
Given knowledge of the true pathological condition $D \in \{0, 1\}$, the observed clinical findings $X_1, X_2, \dots, X_n$ are assumed conditionally independent:
\begin{equation}
P(X_1, X_2, \dots, X_n \mid D) = \prod_{i=1}^n P(X_i \mid D)
\end{equation}

This assumption provides two critical operational advantages:
\begin{itemize}
\item \textbf{Mathematical Tractability:} It prevents combinatorial state explosion in the Conditional Probability Tables. Rather than requiring $2^{13} = 8,192$ joint probability cells, the model estimates only independent two-column tables $P(X_i \mid D)$ for each feature, ensuring stable, dense parameters even with 736 training instances.
\item \textbf{Robustness Under Missing Data:} Under conditional independence, when an evidence variable $X_k$ is unobserved, it drops out of the likelihood quotient cleanly without requiring parameter marginalization over unobserved joint states.
\end{itemize}

\section{Parameter Learning via Discrete Maximum Likelihood Estimation}

Parameters of the Conditional Probability Tables are estimated using Discrete Maximum Likelihood Estimation (MLE). For any state $x$ of evidence variable $X_i$ and disease state $d \in \{0, 1\}$:
\begin{equation}
P(X_i = x \mid D = d) = \frac{N(X_i = x, D = d)}{N(D = d)}
\end{equation}
where $N(X_i = x, D = d)$ represents the joint frequency count in the training split. Prior probabilities $P(D = 0) = 0.4470$ and $P(D = 1) = 0.5530$ are learned directly from training split class frequencies.

All learned CPTs are validated using mathematical consistency checks $\sum_x P(X_i = x \mid D = d) = 1.0$ and exported to a versioned JSON repository at \texttt{models/cpt\_tables.json}.

\section{Exact Inference via Variable Elimination}

During prediction, patient evidence $E = \{ X_{e_1} = v_1, \dots, X_{e_k} = v_k \}$ is queried against the network. The posterior probability of coronary heart disease is computed by Bayes' Theorem:
\begin{equation}
P(D = 1 \mid E) = \frac{P(D = 1) \prod_{j=1}^k P(X_{e_j} = v_j \mid D = 1)}{\sum_{d \in \{0, 1\}} P(D = d) \prod_{j=1}^k P(X_{e_j} = v_j \mid D = d)}
\end{equation}

Any unobserved variable $X_u \notin E$ is summed out (marginalized) over its discrete domain $\mathcal{X}_u$:
\begin{equation}
P(D \mid E) \propto \sum_{x_u \in \mathcal{X}_u} P(D, E, X_u = x_u) = P(D, E)
\end{equation}
This allows clinicians to input anywhere from 1 to 13 diagnostic tests with full mathematical integrity.

\section{Evaluation Metrics and Calibration Considerations}

In medical diagnosis, overall classification accuracy is insufficient. A missed diagnosis of coronary disease (False Negative) can have catastrophic consequences for patient survival. Accordingly, the model is evaluated using a multi-dimensional metric framework:

\begin{equation}
\text{Sensitivity (Recall)} = \frac{TP}{TP + FN}, \qquad \text{Specificity} = \frac{TN}{TN + FP}
\end{equation}
\begin{equation}
\text{Precision (PPV)} = \frac{TP}{TP + FP}, \qquad F_1\text{-score} = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}
\end{equation}

Furthermore, to measure the fidelity of posterior probability outputs, the **Brier Score** is evaluated:
\begin{equation}
\text{Brier Score} = \frac{1}{N} \sum_{i=1}^N \left( \hat{p}_i - y_i \right)^2
\end{equation}
where $\hat{p}_i = P(D = 1 \mid E_i)$ and $y_i \in \{0, 1\}$. A lower Brier score denotes superior probability calibration.

\section{Experiment Tracking with MLflow}

All experimental runs, hyperparameters, training metrics, test metrics, and serialized artifacts are tracked in MLflow using an SQLite-backed registry (\texttt{sqlite:///mlruns/mlflow.db}). The tracking repository logs:
\begin{itemize}
\item Network parameters: number of nodes (14), directed edges (13), and estimator type (\texttt{DiscreteMLE}).
\item Dataset provenance: raw file MD5 checksum and training/test row counts.
\item Git commit SHA: for source-code traceability.
\item Artifacts: \texttt{bayesian\_network.pkl}, \texttt{cpt\_tables.json}, \texttt{preprocessor.json}, \texttt{data\_snapshot.csv}, and all diagnostic evaluation plots.
\end{itemize}

\chapter{Discussion \& Conclusion}

\section{Summary of Work}

This project has demonstrated the complete lifecycle of a probabilistic clinical machine learning application using Bayesian Networks and modern MLOps methodologies. By addressing multi-center missingness in the UCI Heart Disease dataset through leakage-free preprocessing and formulating a clinically grounded Diagnostic Naive Bayes network, the system achieves a strong test ROC-AUC of 0.8914, accuracy of 82.07\%, sensitivity of 85.29\%, and a Brier calibration score of 0.1433. The application is served via FastAPI, presented through an interactive Streamlit UI, tracked in MLflow, containerised in Docker, and monitored through operational logging.

\section{Clinical Significance}

The Bayesian Network approach provides distinct clinical advantages:
\begin{itemize}
\item **Flexibility Across Care Settings:** Community clinics lacking fluoroscopy or nuclear stress testing can enter basic demographic and vital data, while tertiary cardiac centers can incorporate advanced imaging findings. In both cases, exact mathematical inference calculates the posterior probability without artificial imputation.
\item **Safety Through Calibration:** The high sensitivity (85.29\%) prioritizes patient safety by minimizing false negative diagnoses, while the low Brier score (0.1433) ensures that calculated probabilities reflect real-world disease incidence.
\end{itemize}

\section{Limitations}

Despite its strengths, the system has several limitations:
\begin{itemize}
\item **Observational Registry Bias:** The historical UCI cohort predominantly features male patients (79\% in the Cleveland subset), which, although audited for fairness, necessitates broader validation across diverse contemporary populations.
\item **Educational Prototype Status:** In compliance with healthcare software regulations (FDA / CE mark), this application is an educational prototype and must not be used as a standalone diagnostic instrument.
\end{itemize}

\section{Future Scope}

Future extensions include:
\begin{itemize}
\item Transitioning from static Naive Bayes to Dynamic Bayesian Networks (DBNs) to model longitudinal disease progression over multiple patient visits.
\item Incorporating continuous-node Bayesian Networks (Linear Gaussian models) to eliminate the need for fixed discretization cutoffs.
\item Integrating automated CI/CD retraining workflows using GitHub Actions upon detected covariate drift.
\end{itemize}

\section{Conclusion}

The project demonstrates that machine learning in healthcare must extend beyond offline metrics to address real-world uncertainty, missing evidence, transparency, and operational deployment. By uniting Bayesian graphical modeling with rigorous MLOps practices, the developed application provides a robust, interpretable, and reproducible framework for clinical probabilistic decision support.

\section{API Health and Metadata Endpoints}
The FastAPI backend exposes endpoints for service health verification and model provenance inspection:
\begin{itemize}
\item \texttt{GET /health}: Confirms engine status, system uptime, active model version (\texttt{1.0.0}), and current Git commit SHA.
\item \texttt{GET /metadata}: Returns the 14 network nodes, 13 directed graph edges, training/test sample sizes, dataset MD5 checksum, and feature domains.
\item \texttt{POST /predict}: Primary inference endpoint accepting arbitrary combinations of patient findings and returning calibrated probabilities, risk tiers, and unobserved variable lists.
\item \texttt{POST /predict/batch}: Multi-patient batch inference endpoint.
\end{itemize}

\section{Automated Test Suite Verification}
All core data pipelines, CPT mathematical constraints, inference engines, and API endpoints are tested using the automated test suite in \texttt{tests/test\_pipeline.py}:
\begin{itemize}
\item \texttt{test\_01\_raw\_data\_loading}: Verifies raw dataset integrity (920 records).
\item \texttt{test\_02\_preprocessing\_and\_leakage\_prevention}: Confirms leakage-free train/test splitting (736 vs 184) and absence of null values.
\item \texttt{test\_03\_cpt\_mathematical\_consistency}: Verifies that all learned CPT probability tables sum to 1.0.
